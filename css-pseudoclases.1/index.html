1. Enlaces y ubicación

MDN (:link / :visited) · Ir al objetivo (:target) 

a:link    { color: #2a6fdb; }
a:visited { color: #7b3fb5; }
a:any-link { text-decoration-thickness: 2px; }

Este párrafo se resalta cuando la URL termina en #objetivo-demo (:target).

.objetivo:target { background: #ffd23f; }

3. Formularios

input:required  { border-left: 6px solid #2a6fdb; }
input:valid:not(:placeholder-shown)   { border-color: #1f9d55; }
input:invalid:not(:placeholder-shown) { border-color: #d64545; }
input:disabled  { background: #e6eaef; }
input:in-range  { background: #e8f7ee; }
input:out-of-range { background: #fde8e8; }
input:checked + span { font-weight: 700; }

4. Estructurales

  • Uno (:first-child)
  • Dos (even)
  • Tres (3n)
  • Cuatro (even)
  • Cinco (:nth-last-child(2))
  • Seis (:last-child)
li:first-child { color: #2a6fdb; }
li:last-child  { color: #d64545; }
li:nth-child(even) { background: #eef3fb; }
li:nth-child(3n)   { border-left: 5px solid #ffd23f; }
li:nth-last-child(2) { text-decoration: underline; }
